# Tasbih Website — Version 1

A responsive digital Tasbih/Dhikr counter built with plain HTML, CSS and JavaScript.

## Features
- Dhikr selection
- Custom dhikr
- 33 / 99 / 100 / custom targets
- Tap, +, − and reset controls
- Progress bar
- Daily count, sessions and completed targets
- LocalStorage persistence
- Sound and vibration
- Dark/light mode
- Keyboard Space-bar counting
- Mobile-first responsive design

## Run
No build process is required.

Open `index.html` in a browser, or copy the `tasbih-v1` folder into:
- XAMPP: `htdocs/`
- Apache: your document root
- Nginx: your configured web root

Example:
`http://localhost/tasbih-v1/`
